BlenderのGPUアクセラレーション対応UIを他のアプリケーションから再利用可能にする「BUI」

9 時間前

BUI(Blender's User Interface) はBlenderの洗練されたユーザーインターフェースを、独立したUIライブラリとして再利用可能にするプロジェクトです。

GitHub - ppmpreetham/BUI: Blender's GPU Accelerated UI, Decoupled from it's original codebase. Supports Rust, Python, JS, Lua, C & C++. Twice as good as GPUI · GitHub

BlenderのUIは使いやすさ・効率性・高速応答性において高く評価されています。BUIはBlenderのUIの特性をBlenderがインストールされていなくても他のアプリケーションから利用できるよう、独立した小さなC言語製コアに移植したUIライブラリであり、多様なプログラミング言語から利用可能です。

BUIは、Blender特有の直感的で効率的なUI操作を再現します。例えば以下のような操作が対象となります。

上記の機能は、C言語に移植されたBlenderのウィジェットコードを描画コードとして実装され、「キット」と呼ばれる小さなCランタイムに管理されています。キットの上にはバインディングと呼ばれる薄いレイヤーがあり、様々な言語がバインディングを通じてキットと通信できます。

・ Rust ：HTML/CSSライクなマークアップ(rsx!)・Tailwind CSS・React風フック・gpuiスタイルのビルダー構文をサポート、ブラウザエンジンなしでWebライクなUIをネイティブで実現可能

・ JavaScript/React ：React 19.3レンダラーを提供し、Svelte 5やDOMライクなAPIもサポート、Node.jsやBun上で動作しネイティブウィンドウにレンダリング

・ Lua ：Lua 5.4を埋め込み、BUIキット全体をネイティブモジュールとして公開

パフォーマンスや効率性に優れているのもBUIの特徴の一つです。

・ CPU/GPUレンダリング ：デフォルトではCPUレンダラーを使用するが、オプションでDirect3D 11((Windows)またはOpenGL 3.3(Linux)を使用するGPUレンダラーも利用可能なため、大規模なシーンやアニメーションでパフォーマンス向上が期待できる

また、BUIはBlenderのライトテーマ・ダークテーマをデフォルトでサポートしており、実行時に切り替えることができます。さらに、JSONファイルを使用して独自のテーマを作成することも可能です。

導入する場合、pip(Python)・cargo(Rust)・npm(JavaScript)などを通じて簡単にインストールできます。ビルドシステムにはCMakeが使用されており、ソースからのビルドも可能となっています。

BUIは既に多くの機能が完成していますが、アクセシビリティサポート・一部のテキスト機能(IME・フォントフォールバック)・macOSでのGPUレンダリング・Waylandネイティブサポートなどまだ開発途上・実験的な部分もあります。将来的にはWebAssembly対応・ますます多くの言語バインディング・アクセシビリティ機能の追加などが計画されています。
