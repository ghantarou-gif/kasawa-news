16:T12ed,複数のVPNを利用していると接続先ごとに異なるアプリやコマンドを使い分ける必要があり、通信状態や通信経路の確認も複雑になります。そこで WireGuard ・ OpenVPN などの接続管理を一つの画面にまとめ、通信速度・遅延のリアルタイム監視・情報漏えいの検出・VPN切断時の通信遮断まで行える無料のオープンソースツールが「 Vortix 」です。

Harry-kp/vortix: VPN terminal UI (TUI) for WireGuard and OpenVPN with multi-tunnel control, real-time telemetry, and leak guarding.

Vortixは既存のVPNクライアントでは把握しにくかった通信状態や通信経路を可視化するために開発された Rust 製のソフトウェアで、OSにインストールされているWireGuardやOpenVPNを制御する仕組みです。対応OSはmacOSおよびLinuxで、キーボードによる操作を中心とした「ターミナルUI(TUI)」のほかコマンドによる操作にも対応しています。

今回は Ubuntu にVortixをインストールします。記事作成時点の 最新版 はバージョン0.6.0だったので、 Releases ページの「Assets」から「vortix_0.6.0_amd64.deb」をダウンロード。

ダウンロードしたファイルのあるディレクトリでターミナルを開き、以下のコマンドを実行してインストール。

sudo apt install ./vortix_0.6.0_amd64.deb

VortixでVPNに接続するには接続設定ファイルが必要で、「i」キーを押すと表示される「Add a VPN」の入力欄にファイルのパスを入力します。WireGuardでは拡張子が「.conf」、OpenVPNでは「.ovpn」などの設定ファイルを利用できます。

VPNへの接続中は通信速度や遅延時間などがリアルタイムで更新されるため、ファイルのダウンロードや動画の再生などによる通信状況の変化をグラフで確認できます。

通信状況として確認できる主な項目は以下の通り。

VPNで通信を暗号化していても本来のIPアドレスが外部から見えていたり、ドメイン名からIPアドレスを調べる「 DNS 」の問い合わせがVPNの外へ流れたりする場合があります。そこでVortixに搭載されている「Security Guard」では本来のIPアドレスと外部から見えるIPアドレスの比較やDNSの設定状況、暗号化方式などを検査し、取得した情報を基に通信の保護状態を判定します。

通信の保護状態は以下の3段階で表示されます。

また、保護状態に問題がある場合は「f」キーを押すと判定の根拠となった情報が表示され、どの項目に問題があるのかを調べることができます。

VPNが突然切断されると通信が通常のインターネット回線へ流れる場合がありますが、VortixではOSのファイアウォールを利用してVPN経由以外の通信を原則遮断する「キルスイッチ」が利用できます。ただし、OSの再起動からVortixがキルスイッチを再適用するまでの間は保護の対象外となり、キルスイッチや権限管理に関する第三者によるセキュリティ監査も記事作成時点では未実施とのこと。

キルスイッチには以下の3種類のモードが用意されています。

Vortixでは原則として全ての通信をVPN経由にする「フルトンネル」と特定のネットワーク宛ての通信のみをVPN経由にする「スプリットトンネル」を組み合わせて複数のVPNへ同時に接続できます。例えば通常のインターネットへの接続にはWireGuardを利用しながら社内サーバーへの接続にはOpenVPNを利用するといった使い分けが可能です。なお、複数のVPNで通信経路が競合した場合は既存のVPNから切り替えるか新しい接続をキャンセルするかを選択できます。

バージョン0.6.0からはWireGuardをベースにデバイス同士を接続するプライベートネットワークを構築できる NetBird にも対応し、別途NetBirdのコマンドをインストールすることでインターネット接続用のVPNと併用できるようになりました。
