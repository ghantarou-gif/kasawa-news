5:Tbb3,Claude Code や Codex などを並行して利用すると、どのAIコーディングエージェントやモデルへどれだけトークンを使ったのか全体像を把握しにくくなります。そこで使えるのが複数のエージェントのローカル履歴を自動収集し、モデル別・日別・セッション別の利用量やAPI料金換算のコストをまとめて確認できる「 AgentsView 」です。

kenn-io/agentsview: Local-first session search, analytics, insights, and token use statistics for coding agents, supporting Claude Code, Codex, and more than 20 other agents.

AgentsViewをサーバーモードで起動。

サイドバーに会話の履歴が表示されているので任意の履歴をクリックすると、ユーザーの指示・AIの返答・ツール呼び出しが時系列でたどれます。

検索欄をクリックもしくは「Ctrl+K」で検索用ウィンドウが立ち上がるので検索したい単語を入力すると、複数のAIエージェントを横断して過去の会話を検索可能、日本語での検索も正常に利用できました。

「使用量」画面ではトークン情報が記録されたセッションを集計し、モデル別・日別の利用量とAPI料金に換算した推定コストがグラフで表示されます。

「活動」画面ではエージェントを実行した時間帯・同時実行数・アクティブ時間・アイドル時間が分かります。

「評価」アイコンをクリックするとツール実行の失敗・再試行・コンテキストの負荷などを分析し点数に換算して評価します。

「解析」アイコンをクリックするとツールの実行時間が一覧で表示されます。

「リコール」は過去の会話から手順や注意点など再利用できる知識を抽出する実験的機能で、根拠となった発言を確かめて承認・保留できます。

MCPサーバーを介してAIエージェント自身が過去のセッションを検索し、以前の作業内容を参照できます。

複数PCの履歴をPostgreSQLへ統合するほか、ClickHouseやDuckDBを使った分析も可能です。

今回はWindows 11にインストールします。 公式手順 からwindowsのインストールコマンドをPowerShellで実行。

インストールが完了したら別のPowerShellを起動し「agentsview server」コマンドを実行。

AgentsViewは日本語にも対応しており、各AIエージェントのログも自動的に収集されるため、導入後の手間はほとんどかかりません。複数のAIコーディングエージェントを使い分けている環境では、過去の作業内容を振り返ったり、各エージェントの利用状況を把握したりする際に役立つツールとなっています。
