17:Te9f,予約管理システムではカレンダーとの同期やオンライン会議サービスとの連携・メール通知など必要とする機能に応じて利用条件が変わることがあります。そこで、予約ページの作成・複数カレンダーを使った重複予約の防止・ビデオ会議室の自動生成・確認メールの送信・Webサイトへの埋め込みなどの機能をまとめて搭載し、セルフホスト版なら予約件数の制限もなく無料で使えるオープンソースのスケジュール管理システムが「 Tymeslot 」です。

Tymeslot/tymeslot: Open-source meeting scheduling platform built with Elixir/Phoenix LiveView. Self-host or use the managed cloud at tymeslot.app.

例として「15分の短い相談」「30分の打ち合わせ」などが予約できるページで訪問者がいずれかの予定を選択するとします。今回は「Quick Chat」を選択し「Next」をクリック。

日付と時間を選択して「Next Step」をクリック。

申込みフォームが表示されるので「Your Name」に名前、「Email Address」にメールアドレスを入力し「Book Meeting」をクリック。

受付時間を設定することで予約時に対応できる時間だけ表示可能。

さらに Google Calendar ・ Microsoft Outlook ・ iCloud などと連携すると予約ページに表示する空き時間を既存の予定と照合し、ダブルブッキングを防ぎます。

14時から15時までの予約時間が非表示になりダブルブッキングを防げます。

打ち合わせの場所は対面・ビデオ会議・電話などから指定が可能。

複数の選択肢を用意して予約する相手に都合のよい方法を選んでもらうこともできます。

Google Meet ・ Microsoft Teams ・ Zoom などのサービスを接続しておけば、ビデオ会議が選ばれた際に専用の会議室URLを自動生成できます。

予約ページには「Quill」「Rhythm」の2種類のテーマが用意され、背景や色を変えたり独自のWebサイトへ直接予約フォームを埋め込んだりできます。

埋め込み方法はページ内表示・ポップアップ・通常のリンク・フローティングボタンの4種類が用意されています。

そのほか、予約時の質問項目・ Slack もしくは Telegram への通知・Webhookによる外部連携・ Stripe 決済にも対応しています。

なお、UIに日本語表示は用意されていませんでしたが、予約やデータの登録など利用においては日本語を使用しても問題なく利用できました。

今回はWindowsに Docker Desktop と Git for Windows のGit Bashを用意した環境で構築します。作業フォルダーでtymeslotフォルダーを作成し公式のDocker Compose設定ファイルと.envを取得します。

続いて署名用の秘密鍵を生成し出力された値をコピー。

SMTP_HOST=host.docker.internal

登録フォームが表示されるので「EMAIL ADDRESS」にメールアドレス、「PASSWORD」にパスワードを入力して「Sign up」をクリック。

承認用のリンクが記載されたメールが送信されます。

メールを確認して「Confirm Email & Get Started」をクリックし承認手続きを完了します。

初期ウィザードが表示されればTymeslotの構築作業は完了です。
