脆弱性の発見数、1年で2倍超 Microsoft製品も月100件から1000件超に……AIで一変

3 日前

米Microsoftが毎月公開しているWindowsのセキュリティ更新プログラム。11月は1000件以上の脆弱性が修正された。他社の製品も含めると、2026年に入って発見された脆弱性は10万件を超え、すでに25年の倍以上だ。AIの進化に伴い脆弱性の発見とそれを悪用した攻撃が激増する中で、パッチを適用する側はどう対処すればいいのか。

Microsoftが11月の月例更新プログラムで修正した脆弱性は計1093件に上る。うち63件が、深刻度の最も高い「緊急」の分類だった。Outlookのなりすましの脆弱性（深刻度「警告」）は、更新プログラムが公開された時点で悪用が確認されていた。

米セキュリティニュースサイトの Krebs On Security によると、Microsoftが26年に入って修正した脆弱性は、これで5100件を突破した。1年前の平均が月に平均100件前後だったことを考えると、とてつもなく増えている。その理由についてMicrosoftは、AIの進化に助けられて、これほど大量の脆弱性を発見して修正できるようになったと説明しているという。

Microsoftと前後して、米Appleや米Google、米Adobe、米Mozillaなどもセキュリティ更新プログラムを公開し、iOSやWebブラウザなどの脆弱性を修正した。

英メディアの Register によれば、今年に入ってCVE（共通脆弱性識別子）が割り当てられた脆弱性は、全ベンダーを合わせて11月13日の時点で10万件を突破した。これは25年の年間合計の2倍以上にあたる。

米セキュリティ企業VulnCheckの専門家はRegisterに対し「10万件というと非常に多く聞こえるが、あと数年もすれば『たった10万件だった頃を覚えているか？』と言っているだろう」と予測する。

しかも、セキュリティ更新プログラムが公開されてから、その脆弱性が攻撃に利用されるまでの時間は短くなる一方で、ユーザーによる更新プログラムの適用が間に合わないこともある。

セキュリティ企業の米CrowdStrikeによれば、26年1月～6月にかけて確認した、検証用のプログラムコードが悪用された攻撃のうち、88％はPoCコードの公開から48時間以内に発生していた。中国との関係が指摘される「Vault Panda」「Genesis Panda」などのサイバー犯罪集団はさらに速く、24時間以内に攻撃を開始しているという。

AIの普及に伴い、この時間はさらに短くなっている。例えばVulnCheckが米Copeland製の冷蔵・冷凍設備管理システムに存在する脆弱性の情報を公開したところ、わずか数分で攻撃の兆候をとらえたという。欧州のスーパーで大量の食品が廃棄される事態を招いたサイバー攻撃で悪用されたのが、そうした脆弱性だった。

ただし、26年にCVEが割り当てられた10万件あまりの脆弱性のうち、実際の攻撃に利用されたのはごく一部にすぎない。 VulnCheckが独自にまとめている「悪用が確認された脆弱性（KEV）」リスト に追加されたのは1425件。米サイバーセキュリティ・インフラセキュリティ庁（CISA）が管理するKEVリストでは298件にとどまる（11月18日時点）

ユーザー側にとっては、OSやエンドポイントソフトウェアなどの脆弱性修正に加えて、インターネットに接続されたエッジデバイスやIT管理ツール、リモートアクセスツールなどの「エクスポージャー（露出）」管理も欠かせない。

Krebs On Securityによると、米セキュリティ企業Ivantiの専門家クリス・ゲッテル氏は「そうした資産を迅速に特定し、露出を確認し、確認された悪用に対処できるチームは、攻撃者が実際に悪用しているごく少数の脆弱性に集中して、残りの脆弱性については通常のパッチ適用サイクルで対応できる」とアドバイスしている。
