15:Tf11,仕事や日常生活の予定をカレンダーで管理し作業内容をToDoアプリに登録していると、予定とタスクをそれぞれ確認する必要があります。この2つの機能を1つのタイムラインに統合し、空き時間へタスクを割り当てたり Googleカレンダー ・ Notion ・ Todoist などと双方向同期したりできる無料のオープンソースアプリ「Mitra」を実際に使ってみました。

ブラウザでMitraを開くとカレンダーモードで起動します。カレンダーモードでは以下の表示形式が選択可能です。

カレンダーで時間の範囲をドラッグすることで登録が可能、例として「Week」の画面で水曜日の11時から12時までをドラッグ。

予定の登録フォームが表示されるのでタイトル部分に「定例会議」と入力します。

登録した予定は曜日の列に色付きのブロックとして現れ、ブロックをドラッグすれば開始時刻を変更でき、上下の端を動かせば所要時間も調整できます。

サイドメニューの「Planning」をクリックして「Add Task」をクリックし「資料作成」というタスクを登録すると、まだ作業日時を決めていない項目として「Unscheduled」に登録されます。

タスクを開いて「Due date」に締め切り「Estimate」に必要な作業時間を設定。

作成したタスクをカレンダーにドラッグすると設定した見積もり時間に合わせてタスクが配置されます。

タスクを別の日へ動かしたり「Unscheduled」へドラッグして戻したりできるため、急な予定が入った場合も作業計画を組み直せます。

さらに「記事作成」「校正」などをタスクとして登録し、「Subtask of」で親子関係を設定すると大きな仕事を小さな作業に分けて管理できます。

「記事作成」タスクの「Blocked by」に「資料作成」を指定すると依存関係が設定でき、作業の順序が矢印で表示されます。

外部サービスとの連携はサイドバー下部の「Add Integration」から設定し、既存のカレンダーやタスクをMitra上へ読み込めます。

対応する接続先は CalDAV ・Googleカレンダー・Appleカレンダー・Notion・Todoist・ Tempo で、公開ICSカレンダーについては読み取り専用の購読に対応します。なお、接続先で対応する項目は双方向に同期される一方、例えばTodoistの締め切りと作業時間には有料プランが必要などサービスごとの条件があります。

Mitraはスマートフォンのブラウザからも利用でき、ホーム画面に追加すると独立したアプリのように開ける「PWA」に対応しています。

また、 MCP という仕組みで Claude Code や Cursor などのAIから予定を確認・変更する機能も備えています。

今回はWindowsに Docker Desktop と Git for Windows のGit Bashを用意した環境で構築します。作業用フォルダーを作成し、以下のcompose.yamlを保存。

image: ghcr.io/a11delavar/mitra:latest

- ./mitra-data:/app/data

「Add integration」ではカレンダーの接続先を追加できます。最初の接続先として「Mitra」をクリック。

「Calendar name」にカレンダーの名前を記入し「Save」をクリック。

作成したカレンダーが表示されれば導入完了です。
