5:Tdb5,Appleが2026年10月末に発表した「 PROLED XDRディスプレイ搭載MacBook Pro 」では、10年ぶりに天板のAppleロゴが光ります。この光るAppleロゴは消灯可能であることが明らかになりました。

Appleが2015年3月に発売した12インチMacBookから、天板にあるAppleロゴは発光しない金属製のロゴに変わりました。なお、MacBook Proは 2016年10月に発売されたモデル 、MacBook Airは WWDC 2017 で発表されたマイナーチェンジモデルが光るAppleロゴを搭載していた最後のモデルです。

2026年10月末に発表されたPROLED XDRディスプレイ搭載MacBook Proは、10年ぶりに光るAppleロゴが復活しました。

PROLED XDRディスプレイ搭載MacBook ProのAppleロゴは、ディスプレイの明るさに連動しており、ディスプレイが明るければ明るいほど強く光ります。また、Appleロゴの光りの強度は周囲の明るさも考慮して決まる模様。

MacBook Proを閉じた状態だと、ロゴはこれまでの光らないAppleロゴと同じように磨き上げられた金属のように見えるそうで、Apple関連メディアの9to5Macは「復活して本当にうれしい」と報じています。

AppleはAppleロゴの点灯の仕組みについて、「内蔵ディスプレイの背面にあるAppleロゴは、Macのスリープが解除されている間は常に点灯します。内蔵画面の明るさのレベルと、コンピュータの環境光センサーが検知した周囲の明るさに応じて、自動的に暗くなったり明るくなったりします。画面の明るさに関係なく、Appleロゴは暗い部屋では暗く、明るい部屋では明るくなります」と説明しています。

Appleによると、Appleロゴの点灯はオフにすることも可能。オフにするには「アプリケーション」フォルダの「ユーティリティ」フォルダにある「ターミナル」を使用する必要があります。なお、ターミナルは検索機能である Spotlight を使って起動することもできます。

ターミナルで以下のコマンドを入力するか、ペーストして「Return」キーを押せばOK。

sudo defaults write com.apple.CoreBrightness LEBacklightMode -int 0

入力を促すメッセージが表示される場合、管理者パスワードを入力して(入力したパスワードはターミナルには表示されません)、「Return」キーを押せばロゴの点灯はオフになります。

この変更はmacOS復旧から起動した場合を含め、すべてのmacOSユーザーアカウントに影響します。また、新しいMacに移行すれば、この設定は新しいMacに転送されます。

Appleロゴの点灯を再び有効にするには、ターミナルで以下のコマンドを入力すればOK。

sudo defaults delete com.apple.CoreBrightness LEBacklightMode

また、macOSを再インストールしても、ロゴの点灯は再び有効になります。
